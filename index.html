A Simple C# Program (برنامج C# بسيط)

💡 الفكرة الجوهرية للسلايد:

يوضح هذا السلايد الهيكل المعماري الأساسي لأي برنامج بلغة C# وكيفية ارتباط الكود الذي نكتبه بمكتبة الأنواع (Type Library) الخاصة بـ .NET عبر فضاء الأسماء System.

📌 تحليل نقاط السلايد بالتفصيل:

  • 1 السطر 1 (using System;): يستدعي فضاء الأسماء System الموجود في مكتبة الأنواع (Type Library) والذي يحتوي على الكلاس Console ودالة الطباعة WriteLine().
  • 2 السطر 3 (namespace Simple): يعرّف فضاء أسماء خاص ببرنامجنا لتنظيم الكلاسات بداخله ومنع تضارب الأسماء.
  • 3 السطر 5 (class Program): يعرّف الكلاس الرئيسي في البرنامج، وفي C# كل دالة يجب أن تكون داخل كلاس.
  • 4 السطر 7 (static void Main()): نقطة البداية (Entry Point) التي يبدأ منها تنفيذ البرنامج؛ كلمة static تعني أنها تعمل بدون إنشاء كائن (Object) من الكلاس، و void تعني أنها لا تُرجع قيمة.
  • 5 السطر 9 (Console.WriteLine("Hi there!");): يستدعي دالة الطباعة لعرض النص Hi there! على شاشة المخرجات ثم ينتقل لسطر جديد.
💻 الكود / الجدول الأصلي في السلايد: C# / .NET 
// SimpleProgram.cs
using System;

namespace Simple
{
    class Program        // declare a class
    {
        static void Main()
        {
            Console.WriteLine("Hi there!");
        }
    }
}
// Output: Hi there!
🔍 تفكيك الكود والمصطلحات سطراً بسطر:
using System;
استيراد فضاء الأسماء System للوصول إلى الكلاس Console مباشرة دون كتابة System.Console في كل مرة.
namespace Simple { ... }
حاوية منطقية تضم الكلاس Program؛ السهم في السلايد يوضح أن namespace Simple يضم class Program وبداخله Main().
class Program
الإعلان عن الفئة (Class) التي تحوي الكود التنفيذي.
static void Main()
الدالة الرئيسية؛ يجب أن يبدأ حرف M بكابيتال (Main) وإلا لن يتعرف عليها المترجم كنقطة انطلاق.
Console.WriteLine("Hi there!");
النداء الفعلي لدالة الطباعة الموجودة داخل class Console ضمن namespace System.
